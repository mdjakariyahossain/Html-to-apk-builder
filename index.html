ⓘ Build process

কীভাবে APK পাবে?

1Generate ZIPএই পেজ থেকে project package তৈরি করো।
2Upload to GitHubZIP extract করে repository-তে সব ফাইল upload করো।
3Run workflowActions → Build Android APK → Run workflow.
4Download APKWorkflow artifact থেকে APK download করো।
